# Medical Summarizer: documentation feature

This folder holds the proposed General Medicine walk-in record brief and its discovery materials. The Kerala clinic is a potential pilot partner; its participation, software, and intake workflow still need confirmation.

| Document | Purpose |
| --- | --- |
| [Pilot brief](pre-visit-record-brief.md) | Agreed workflow, scope, success measure, and later EHR integration path |
| [Clinic discovery and observation](clinic-discovery-and-pilot-observation.md) | Questions for the doctor and a sheet for measuring the current workflow and prototype |
| [Kerala EHR and ABDM research](ehr-abdm-kerala-research.md) | Official sources, terminology, possible integration routes, and unresolved access questions |
| [Glossary](GLOSSARY.md) | Meanings of record brief, clinical note, ABHA, Kerala UHID, HIP, and HIU |
| [Interactive UI prototypes](prototype-record-brief/README.md) | Three desktop and tablet layouts for doctor review, with fictional records and source-linked interactions |
| [Kerala clinic prototype research](kerala-clinic-prototype-research.md) | Primary-source comparison of the three layouts and a test plan for choosing one with the pilot clinic |

The next step is to speak with the General Medicine doctor, identify the clinic's actual record software and existing ABHA or Kerala eHealth workflow, and measure how long thick paper files take to review. A detailed implementation specification follows those observations.
