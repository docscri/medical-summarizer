# Domain documentation

This is a single-context project rooted at `documentation_feature`.

Before feature work, read the root `GLOSSARY.md` and any relevant
decisions in `docs/adr/`. Use the glossary's terms in specs, tickets,
and code. Surface conflicts with an existing decision rather than
silently overriding it.

The `docs/adr/` folder can be created when a decision needs recording;
its absence does not block work.
