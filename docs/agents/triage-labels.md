# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Needs evaluation |
| Needs information | `needs-info` | Waiting for details |
| Ready for agent | `ready-for-agent` | Specified enough to implement |
| Ready for human | `ready-for-human` | Requires human action |
| Won't fix | `wontfix` | Will not be pursued |
