# Issue tracker: GitHub

Specs and tickets for this project are GitHub issues in
https://github.com/docscri/medical-summarizer.

Always name `docscri/medical-summarizer` explicitly when reading or
writing issues. The local `documentation_feature` folder is not a
Git clone of that repository.

Use the connected GitHub tools for issue operations. If the GitHub CLI
is installed later, use `gh` with `-R docscri/medical-summarizer`.

Publish each spec as an issue. Publish each implementation ticket as a
separate issue, linking it to its parent spec. Record blocking issues
with GitHub dependencies when available; otherwise include a
`Blocked by: #...` line in the ticket body.

Use the labels mapped in `docs/agents/triage-labels.md`.
Pull requests are not treated as incoming triage requests.
